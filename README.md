# 🪶 挠痒痒惩罚飞行棋

一个给情侣玩的整蛊桌游（网页版），无需安装任何东西。

## 怎么玩

直接双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开即可。

1. **开局设置**：填写称呼；增删「挠痒工具库」和「固定姿势库」；勾选是否拥有按摩仪道具、是否启用「打脚心」；拖动滑条选择 3~7 层；可自定义挑战奖惩、认输终极惩罚，以及通关终极奖励（默认无）。打开「格子图鉴」还可以增删挑战、游戏格、拷问、奖励的内容。
2. **甩骰子**：只有一个棋子，由被惩罚者甩骰子，顺时针绕棋盘走，走到哪格执行哪格。每局格子布局随机。
3. **姿势系统**：每进入一层（含第一层）自动抽取本层固定姿势，整层保持。默认开启「每层姿势不重复」——抽过的姿势会从轮盘上消失，因此层数上限 = 姿势数量（层数恒 ≥ 3，姿势也不能删到少于层数）；取消勾选后姿势可重复，层数可拉满 7 层、姿势最少保留 1 个。
4. **层间入口**在棋盘中心，碰到自动进入下一层（不会走过头）。难度分温柔/残忍/地狱三档随层数递进（时长最长 30 分钟）。
5. **格子类型**（落格后自动播放抽奖动画）：
   - 🕷️ 惩罚格：**部位、工具、时长三轮盘同时抽**（轮盘上显示的就是最终执行时长），内置倒计时；喊停 = 加时 3 分钟，休息后继续
   - ⚔️ 挑战格：忍笑 / 木头人 / 静音 / 举手 / 脚趾倔强 / 背诗 / 口算 / 闻袜子 / 憋气 / 撒娇 / 求饶……失败触发加倍惩罚（奖惩可自定义）
   - 🎯 游戏格：猜数字 / 24点 / 脚心写字猜字，赢了通过，输了受罚
   - 👋 打脚心（需勾选启用）：抽中该工具则忽略部位，改为打脚心，下数 = 时长分钟数 × 2
   - 📳 按摩仪格：「固定」绑上脚心一直响，走到「取下」格才解脱
   - 🎤 拷问格、🧦 袜子格、🎁 奖励格（含免罚护体卡、🎲重抽卡：判决出来后可整套重抽）
   - 🔄 反杀格（第二层起，极稀有，反过来挠对方）、🌀 传送门（仅末层，摔回上一层）
6. **只有终点必须正好踩中**，走过头原地不动。
7. **随时可以认输**，但认输 = 终极惩罚（内容保密，认输后才揭晓）。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 界面样式与动画 |
| `game.js` | 全部游戏逻辑（骰子、轮盘、计时器、音效均为纯前端实现，无需联网、无需素材） |

工具库和称呼会自动保存在浏览器本地（localStorage），下次打开不用重新设置。

> 温馨提示：游戏内容请以双方自愿、安全、适度为前提，随时尊重对方的真实意愿。
