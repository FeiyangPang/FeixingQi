# 🪶 挠痒痒惩罚飞行棋

一个给情侣玩的整蛊桌游（网页版），无需安装任何东西。

## 怎么玩

直接双击 `index.html`，用浏览器（推荐 Chrome / Edge）打开即可。

1. **开局设置**：填写两人的称呼，按手里实际有的工具增删「挠痒工具库」（残忍度会影响后期被抽中的概率）。
2. **甩骰子**：只有一个棋子，由被惩罚者甩骰子，顺时针绕棋盘走，走到哪格执行哪格。
3. **三层棋盘**：温柔层 → 残忍层 → 地狱层，层间入口在棋盘中心，**碰到入口自动进入下一层**（不会走过头）。越往上工具越残忍、时长越长（最长 30 分钟）。
4. **格子类型**（落格后自动播放轮盘抽奖动画，直接给出最终判决）：
   - 🕷️ 惩罚格：自动抽工具 + 抽时长，内置倒计时；中途撑不住喊停 = 自动加时 3 分钟，休息后继续
   - ⚔️ 挑战格：忍笑 / 木头人 / 静音 / 举手 / 脚趾倔强 / 背诗 / 口算 / 闻袜子 / 憋气 / 撒娇 / 求饶……失败触发加倍惩罚
   - 🎤 拷问格：招供照做可过关，硬挺就挨挠
   - 🧦 袜子格、🎁 奖励格（含免罚护体卡）、🔄 反杀格（极稀有，反过来挠对方）
   - 🌀 传送门（仅地狱层）：踩中摔回第二层
5. **只有终点必须正好踩中**，走过头原地不动。
6. **随时可以认输**，但认输 = 终极惩罚。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 界面样式与动画 |
| `game.js` | 全部游戏逻辑（骰子、轮盘、计时器、音效均为纯前端实现，无需联网、无需素材） |

工具库和称呼会自动保存在浏览器本地（localStorage），下次打开不用重新设置。

> 温馨提示：游戏内容请以双方自愿、安全、适度为前提，随时尊重对方的真实意愿。
