📜 规则速览

  • 只有一个棋子，由被惩罚者甩骰子，顺时针绕棋盘走，走到哪个格子就接受哪个格子的内容。每局格子布局随机打乱。
  • 🧘 每进入一层（含第一层）自动抽取本层固定姿势，整层保持该姿势。
  • 🕷️ 惩罚格：部位、工具、时长三个轮盘同时开抽！倒计时开始挠，中途撑不住喊停 = 加时 3 分钟，休息后继续。
  • 👋 打脚心（需勾选启用）：抽中这个工具则忽略部位，直接打脚心，下数 = 时长分钟数 × 2。
  • 🎲 重抽卡（奖励格获得）：判决出来后可以用掉一张，把工具、部位、时长整套重抽。
  • 🎯 游戏格：猜数字 / 24点 / 脚心写字猜字，赢了继续前进，输了接受三连抽惩罚。
  • 📳 按摩仪格（需勾选道具）：抽中「固定」后按摩仪会一直绑在脚心，直到走到「取下」格。
  • ⚔️ 挑战格：完成挑战安全通过，失败则触发更残忍的加倍惩罚。
  • 🎤 拷问格：如实招供/照做可以过关，硬挺就要挨挠。
  • 🎁 奖励格：休息、喝饮料、前进、护体卡、重抽卡，极少出现，且越往后越少。
  • 🔄 反杀格：极其稀有（第二层起才有）！被惩罚者反客为主，抽轮盘挠协助者！
  • 🌀 传送门（仅最后一层）：踩中直接摔回上一层……
  • 🪜 层间入口在棋盘中心：碰到入口自动进入下一层，不会走过头。
  • 🏁 只有终点必须正好踩中，走过头原地不动。随时可以认输，但认输 = 终极惩罚：被彻底拘束，所有道具伺候，时长由对方心情决定。
